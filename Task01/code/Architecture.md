# Task 01 source map

The integrated project source is located under the root `src` directory:

- Application entry point: [Main.java](../../src/main/java/parking/app/Main.java)
- Login screen: [LoginFrame.java](../../src/main/java/parking/ui/LoginFrame.java)
- Main dashboard: [DashboardFrame.java](../../src/main/java/parking/ui/DashboardFrame.java)

The task folders document the assignment stages, while `src/main/java` is the single
canonical source tree compiled by Maven.
